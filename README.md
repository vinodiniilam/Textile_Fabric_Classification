**PROJECT OVERVIEW:**
This project focuses on classifying Indian textile and fabric patterns.
The model analyzes textile images and classifies them into four different categories:
Banarasi
Bandhani
Ikat
Pichwai
**Objective**
The main objective of this project is to develop an image classification model that can automatically identify different textile fabric patterns from input images.
<>This can help in applications such as:
<>Textile pattern recognition.
<>Fabric classification.
<>Digital textile cataloging.
<>E-commerce product categorization.
<>Traditional Indian textile identification
**DATASET:**
<>Banarasi
<>Bandhani
<>Ikat
<>Pichwai
**DATASPLIT**
The Dataset is divided into :
Training: 1,293 images
Validation: 115 images
Testing: 60 images
